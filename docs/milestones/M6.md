把「商品 + 客户专属价格」变成一个**可对外、可冻结、可追溯**的链接。这是本系统唯一直接面对终端客户的出口，安全与稳定性要求最高。

## 5. 关键设计（摘要，细节以 06 为准）

- token 32 字节随机，库里只存 sha256，明文只返回一次。
- 访问计数用原子 UPDATE + RETURNING 判断超限。
- 价格优先级：SKU 报价 → SPU 报价 → 原价（可配置）→ 询价。
- 快照 payload 只含白名单字段（§5），禁止成本价、精确库存、内部备注。
- `Cache-Control: private, no-store`。
- IP 存哈希。

## 8. 验收清单

```bash
# 建客户 + 报价单
curl -X POST localhost:8080/api/v1/admin/customers -H "Authorization: Bearer $T" -d '{"name":"杭州某某贸易"}'
curl -X POST localhost:8080/api/v1/admin/price-lists -H "Authorization: Bearer $T" \
  -d '{"customer_id":1,"name":"Q4 报价","currency":"CNY","valid_to":"2026-12-31T00:00:00Z"}'
curl -X POST "localhost:8080/api/v1/admin/price-lists/1/items:batch" -H "Authorization: Bearer $T" \
  -d '{"items":[{"spu_id":1,"sku_id":101,"price_cents":4500,"moq":50}]}'

# 生成分享
RESP=$(curl -X POST localhost:8080/api/v1/admin/share-links -H "Authorization: Bearer $T" \
  -d '{"title":"Q4 报价","customer_id":1,"price_list_id":1,"mode":"snapshot","items":[{"spu_id":1}]}')
URL=$(echo $RESP | jq -r .data.url)

# 匿名访问
curl -s "$URL" | jq '.data.items[0].display_price_cents'   # 4500
curl -s "$URL" | grep -c cost_cents                        # 0

# 改价，快照不变
curl -X POST "localhost:8080/api/v1/admin/price-lists/1/items:batch" -H "Authorization: Bearer $T" \
  -d '{"items":[{"spu_id":1,"sku_id":101,"price_cents":9900}]}'
curl -s "$URL" | jq '.data.items[0].display_price_cents'   # 仍是 4500

# 撤销
curl -X POST localhost:8080/api/v1/admin/share-links/1/revoke -H "Authorization: Bearer $T"
curl -s "$URL" | jq .code                                   # 70102

# 访问日志
psql "$DSN" -c "select count(*) from share_visit;"
psql "$DSN" -c "select ip_hash from share_visit limit 1;" | grep -Ec '^[0-9a-f]{64}$'
```

## 12. M6a 管理接口契约

完整请求、状态码与响应字段见 `api/openapi/share.yaml`。本批只注册 §6 中的客户、价目表、条目批量与价格预览共 12 个管理操作；分享链接、访问与询价路由留待 M6b/M6c。

- 客户创建要求 `code/name`；编码在租户内唯一。联系人三个字段分别信封加密，响应固定掩码；`owner_user_id` 默认当前用户，归属变更必须仍在当前数据范围内。
- 价目表要求 `type/name/currency`；`type=customer` 必须指定目标 `customer_id`，`type=default` 的客户为空；生效区间含头不含尾，时间使用 RFC3339 UTC。
- PUT 携带当前 `version`；DELETE 使用 `?version=N` 并软删除。批量请求为 `{version,items:[{spu_id,sku_id,price_cents,moq,note,delete}]}`，最多 500 个不同商品键；SKU 0 表示 SPU，`delete=true` 移除该键。批次原子提交，成功返回 `{success,failed:[],version}`；非法成员整批回滚。
- 价格预览请求为 `{customer_id,price_list_id?,currency,as_of?,allow_fallback_price?,allow_zero_price?,items:[{spu_id,sku_id,quantity}]}`。数量默认 1，原价与零价默认不允许；显式 `price_list_id` 必须属于目标客户，作为第一层客户专属报价。该客户其余有效 customer 单为第二层；default 单为第三层；同币种 SKU 原价为第四层。
- 预览逐项返回 `price_cents/currency/show_price/price_basis/layer_name/as_of`，报价命中时附 `price_list_id/item_id/version/precision/moq/reason`。同层相同精度多命中返回 `409/10004`；先比较层级，再在该层优先 SKU；MOQ 不满足时返回冲突，禁止向低层绕过。
- 所有写入接受可选 `Idempotency-Key`，重放前重新检查权限与数据范围。无权限 `403/20107`，不存在或越权 `404/10003`，版本冲突 `409/10409`，同键异请求 `409/10006`；联系人和备注不进入响应、幂等缓存、审计详情或日志。

本轮偏差：无。分享数据模型实际位于 `docs/03-data-model.md` §8；按本卡 §0、ADR-020 与本次 M6a 指令覆盖旧卡中的迁移号、权限码及价格规则。

## 14. M6b implementation plan (2026-11-08)

**Goal:** Publish immutable quotes with one-time secrets and fail-closed anonymous admission.
**Architecture:** Reuse M6a pricing, tenant/owner authorization, transaction-bound idempotency and the M5c Sealer. Store a public DTO separately from internal source evidence in the existing snapshot; every disclosure rechecks primary database state. Redis stores only scoped content and bounded admission budgets.
**Tech Stack:** Existing Go, Gin, PostgreSQL, Redis, bcrypt and AES-GCM; no new dependency or schema change.
**Spec:** ADR-020 §1/3/4/8, M6-review Q1/Q4/§7.2 and the current M6b task override historical token length and cookie details.

Global constraints: only M6b; no inquiry or visit statistics; no changes to merged migrations, catalog/order or kernel crypto. Anonymous routes are exactly root, verify and item detail. Public DTOs omit internal references, original prices, private notes and exact stock. Existing SPU/SKU references are the explicitly approved membership identifiers.

- [x] Task 1 — `share/token.go`, `token_test.go`, `link_types.go`, `snapshot.go`: generate 16 random bytes with a fixed `v1` framing prefix (24 base64url-alphabet characters, 128 random bits), hash only for lookup, bcrypt cost 12, independent random public content version. - 签发只返回一次相对 API URL；幂等持久结果仅含 `id/status/secret_delivered`，重放没有 URL。密码只存 bcrypt 12，token 只存 SHA-256 和 8 字符前缀。响应丢失只能重新生成；`regenerate` 要求显式 `revoke_old=true/false`，新链接与可选旧链撤销同事务。
- 本批只接受 `snapshot`；生成时在一致事务中冻结确切 SPU/SKU、解析后价格、币种、MOQ 和最早适用有效期。显式选择公开价目表时只解析该单；省略 SKU 子集时冻结当前成员，后续新增不扩入。公开内容版本独立随机，不含内部引用。未批准的图片、描述、任意属性和备注均不输出。
- 客户专属报价必须有密码；verify 只返回 `verified=true`，签发尚未准入的凭据，不扣次数。成功根准入扣一次；详情要求已完成根准入的有效凭据，不扣次数。已准入凭据可以在次数耗尽后读取详情，但不能重新成功打开根页面。
- Cookie 为 host-only、HttpOnly、Secure、SameSite=Lax，服务端校验原始授权期限，最多 7200 秒且不超过冻结有效期。用户已确认采用 A：`Path=/api/v1/share`，以便浏览器向既定三个 API 发送 Cookie；覆盖原指令 `/share`。密封 AAD 绑定用途、租户、token 哈希、链接、内容版本及密码版本；浏览凭据不绑定手机 IP。
- 每个链接和来源的五次错密触发 15 分钟冷却，不锁其他链接或来源；另有既定 10/min/IP 校验预算及入口、链接预算。随机 miss 不创建逐 token 缓存。限流状态只存受限 TTL 的 Redis 键，不属于访问统计。
- 所有匿名响应均 `Cache-Control: private, no-store`、`Referrer-Policy: no-referrer`；失败固定文案“链接暂不可用”、`data=null`。无效、撤销、到期、非成员统一 404/70102；密码门禁 401/70103；限流 429/10005；依赖故障 503/10002。
- 内容缓存键为 `share:content:v1:{tenant}:{token_id}:{content_version}`，值仅为公开 DTO。每次披露先查询主库，再在链接行锁下重新校验状态、父引用与内容版本；撤销与准入以该锁串行。预热缓存不改变撤销结果；DB 或 Redis 故障拒绝返回内容。已在撤销之前准入的在途响应与已下载内容不能收回。
