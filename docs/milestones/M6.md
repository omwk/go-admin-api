## 1. 目标


把「商品 + 客户专属价格」变成一个**可对外、可冻结、可追溯**的链接。这是本系统唯一直接面对终端客户的出口，安全与稳定性要求最高。

## 2. 范围

1. 表：`customer / price_list / price_list_item / share_link / share_snapshot / share_visit / inquiry`（迁移 `000009_share_init`）
2. 客户档案 CRUD

4. 分享链接生成（快照 / 实时双模式）
5. 免登录分享页接口（含密码、次数、有效期）

## 5. 关键设计（摘要，细节以 06 为准）

- token 32 字节随机，库里只存 sha256，明文只返回一次。
- 访问计数用原子 UPDATE + RETURNING 判断超限。
- 价格优先级：SKU 报价 → SPU 报价 → 原价（可配置）→ 询价。
- 快照 payload 只含白名单字段（§5），禁止成本价、精确库存、内部备注。
- `Cache-Control: private, no-store`。
- IP 存哈希。

## 8. 验收清单

```bash
# 建客户 + 报价单
curl -X POST localhost:8080/api/v1/admin/customers -H "Authorization: Bearer $T" -d '{"name":"杭州某某贸易"}'
curl -X POST localhost:8080/api/v1/admin/price-lists -H "Authorization: Bearer $T" \
  -d '{"customer_id":1,"name":"Q4 报价","currency":"CNY","valid_to":"2026-12-31T00:00:00Z"}'
curl -X POST "localhost:8080/api/v1/admin/price-lists/1/items:batch" -H "Authorization: Bearer $T" \
  -d '{"items":[{"spu_id":1,"sku_id":101,"price_cents":4500,"moq":50}]}'

# 生成分享
RESP=$(curl -X POST localhost:8080/api/v1/admin/share-links -H "Authorization: Bearer $T" \
  -d '{"title":"Q4 报价","customer_id":1,"price_list_id":1,"mode":"snapshot","items":[{"spu_id":1}]}')
URL=$(echo $RESP | jq -r .data.url)

# 匿名访问
curl -s "$URL" | jq '.data.items[0].display_price_cents'   # 4500
curl -s "$URL" | grep -c cost_cents                        # 0

# 改价，快照不变
curl -X POST "localhost:8080/api/v1/admin/price-lists/1/items:batch" -H "Authorization: Bearer $T" \
  -d '{"items":[{"spu_id":1,"sku_id":101,"price_cents":9900}]}'
curl -s "$URL" | jq '.data.items[0].display_price_cents'   # 仍是 4500

# 撤销
curl -X POST localhost:8080/api/v1/admin/share-links/1/revoke -H "Authorization: Bearer $T"
curl -s "$URL" | jq .code                                   # 70102

# 访问日志
psql "$DSN" -c "select count(*) from share_visit;"
psql "$DSN" -c "select ip_hash from share_visit limit 1;" | grep -Ec '^[0-9a-f]{64}$'
```

| # | 验收项 | 通过标准 |
|---|---|---|
| 1 | token 安全 | 库里无可逆值；响应只给一次 |
| 2 | 快照冻结 | 改价/改商品不影响已发链接 |
| 3 | 价格优先级 | 四级规则各有单测 |
| 4 | 白名单字段 | 响应不含成本价/精确库存/内部备注 |
| 5 | 访问控制 | 过期/超次/撤销/密码错分别返回对应码 |
| 6 | 并发计数 | 100 并发、max_views=10，恰好 10 次成功 |
| 7 | 限流 | 超频返回 429 |
| 8 | 日志脱敏 | 无明文 IP、无完整 token |
| 9 | 询价 | 提交后后台可见并通知 |

## 12. M6a 管理接口契约

完整请求、状态码与响应字段见 `api/openapi/share.yaml`。本批只注册 §6 中的客户、价目表、条目批量与价格预览共 12 个管理操作；分享链接、访问与询价路由留待 M6b/M6c。

- 客户创建要求 `code/name`；编码在租户内唯一。联系人三个字段分别信封加密，响应固定掩码；`owner_user_id` 默认当前用户，归属变更必须仍在当前数据范围内。
- 价目表要求 `type/name/currency`；`type=customer` 必须指定目标 `customer_id`，`type=default` 的客户为空；生效区间含头不含尾，时间使用 RFC3339 UTC。
- PUT 携带当前 `version`；DELETE 使用 `?version=N` 并软删除。批量请求为 `{version,items:[{spu_id,sku_id,price_cents,moq,note,delete}]}`，最多 500 个不同商品键；SKU 0 表示 SPU，`delete=true` 移除该键。批次原子提交，成功返回 `{success,failed:[],version}`；非法成员整批回滚。
- 价格预览请求为 `{customer_id,price_list_id?,currency,as_of?,allow_fallback_price?,allow_zero_price?,items:[{spu_id,sku_id,quantity}]}`。数量默认 1，原价与零价默认不允许；显式 `price_list_id` 必须属于目标客户，作为第一层客户专属报价。该客户其余有效 customer 单为第二层；default 单为第三层；同币种 SKU 原价为第四层。
- 预览逐项返回 `price_cents/currency/show_price/price_basis/layer_name/as_of`，报价命中时附 `price_list_id/item_id/version/precision/moq/reason`。同层相同精度多命中返回 `409/10004`；先比较层级，再在该层优先 SKU；MOQ 不满足时返回冲突，禁止向低层绕过。
- 所有写入接受可选 `Idempotency-Key`，重放前重新检查权限与数据范围。无权限 `403/20107`，不存在或越权 `404/10003`，版本冲突 `409/10409`，同键异请求 `409/10006`；联系人和备注不进入响应、幂等缓存、审计详情或日志。

本轮偏差：无。分享数据模型实际位于 `docs/03-data-model.md` §8；按本卡 §0、ADR-020 与本次 M6a 指令覆盖旧卡中的迁移号、权限码及价格规则。
