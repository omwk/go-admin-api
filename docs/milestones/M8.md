## 1. 目标

把「散落在脚本里的外部 API」变成一个受控入口：统一鉴权、限流、日志、可见性。**本里程碑不收费**（计费在 M9），但要把计量字段埋好。

## 2. 范围

1. 表：`api_route / api_client / api_client_secret / api_client_route / api_call_log`（迁移 `000011_gateway_init`）
2. HMAC 签名鉴权中间件
3. 路由管理（代理 / 内置 handler）
4. 三层限流
5. 反向代理（超时、重试、熔断、SSRF 防护）
6. 调用日志（异步批量写）
7. 内置路由：`/usage`、`/balance`、`/routes`
8. 管理端：路由、应用、密钥、授权、日志查询

## 3. 不做

- 不做计费/扣费（M9）
- 不做自助注册
- 不做 API 文档门户（先用静态 markdown/OpenAPI）
- 不做 GraphQL
- 不做请求/响应体全文存储（只存大小与哈希）

## 5. 关键设计（摘要）

- 签名串与校验顺序严格按 `docs/07-gateway-billing.md` §3，**nonce 先占位再验签**。
- 路由匹配：精确优先，其次 `/*` 前缀；不支持正则。
- 代理只透传白名单头；`Authorization`/`Cookie` 一律丢弃。
- SSRF：https-only + 解析后 IP 校验（禁内网段）。
- 日志异步批量写，进程退出前 flush。
- 限流 key 分三层，任一超限即 429。

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/open/v1/orders/{id}/status` | 显式授权订单的本地状态；`id` 为应用专属公开 ULID | HMAC + 路由授权 + 逐订单授权 + owner 当前范围 |

- 人工确认（本次会话选择 A）：新增 `api_client_resource_grant`，按 tenant/client/order 绑定独立公开 ULID；应用显式订单上限与 owner 当前 `trade:order:read` 和店铺范围取交集。owner 的 super/all 不扩大应用订单上限。
- 新迁移为 `000017_gateway_init`（落地时最大号 +1）；`api_call_log` 仅建月分区表，本批没有调用日志写入、计量、配额或限流。
- 独立 `/open/v1` dispatcher 是代码发布白名单，未知方法/路径、未登记能力、disabled/private/付费配置均拒绝；不修改 M6 share 入口白名单。
- nonce 按应用共享，Redis TTL=600s，覆盖 ±300s 有效时间区间；先占位后验签，失败保留；DB/Redis 不可验证时 503 拒绝。
- 401/80101、80102、80103 统一文案“应用凭证不可用”（本次验收明确要求）；其余错误遵循评审 §7，details 统一省略。
- 管理写接口支持 `Idempotency-Key`；密钥交付的重放只返回 `{"delivered":true}`，不保存或重放明文 secret；首次交付 `Cache-Control: private, no-store`。

### 原 M8 总体验收规划（后续批次适用）

```bash
# 建应用（拿 secret）
APP=$(curl -X POST localhost:8080/api/v1/admin/api-clients -H "Authorization: Bearer $T" -d '{"name":"demo"}')
APP_ID=$(echo $APP | jq -r .data.app_id); SECRET=$(echo $APP | jq -r .data.secret)

# 签名脚本（保存为 /tmp/sign.sh）
TS=$(date +%s); NONCE=$(openssl rand -hex 16); BODY=""
BODY_HASH=$(printf "%s" "$BODY" | sha256sum | cut -d' ' -f1)
STS="GET
/api/v1/open/ping

$TS
$NONCE
$BODY_HASH"
SIG=$(printf "%s" "$STS" | openssl dgst -sha256 -hmac "$SECRET" -binary | base64)

curl -s "localhost:8080/api/v1/open/ping" \
  -H "X-App-Id: $APP_ID" -H "X-Timestamp: $TS" -H "X-Nonce: $NONCE" -H "X-Signature: $SIG"

# 重放
curl -s ... -H "X-Nonce: $NONCE" | jq .code      # 80103

# 超时窗
TS_OLD=$((TS-400)); ...                          # 80103

# 未授权路由
curl ... /api/v1/open/other                       # 80104

# 限流
ab -n 200 -c 20 ...                               # 出现 429，未超发

# SSRF
curl -X POST localhost:8080/api/v1/admin/api-routes -H "Authorization: Bearer $T" \
  -d '{"upstream_url":"http://127.0.0.1:8080/x","method":"GET","path":"/api/v1/open/x"}'  # 400
```

| # | 验收项 | 通过标准 |
|---|---|---|
| 1 | 签名 | 正确通过；篡改 body/时间戳/nonce/secret 全部拒绝 |
| 2 | 重放 | 同 nonce 第二次 80103 |
| 3 | 时间窗 | 偏移 > 300s 拒绝 |
| 4 | 授权 | 未授权路由 80104 |
| 5 | IP 白名单 | 非白名单 80105 |
| 6 | 限流 | 压测下通过数 ≤ burst + qps×时长 |
| 7 | 代理安全 | 内网地址、http（非 https）、超大响应被拒/截断 |
| 8 | 日志 | 调用后 1s 内可查；kill -9 不丢已 flush 的 |
| 9 | 熔断 | 上游连续失败后快速失败，30s 后半开 |
| 10 | 密钥轮换 | 两个 secret 并存期都能调用，旧的到期后失效 |
